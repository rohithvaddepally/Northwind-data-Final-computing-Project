# 📊 Northwind Traders – Sales & Purchase Analytics

A full-stack Business Intelligence and Statistical Analysis project using Power BI, MySQL, and Python to analyze and improve business performance for the Northwind Traders dataset.

# 🔍 Project Overview

This project explores sales, purchases, customer behavior, employee performance, and product profitability within the Northwind Traders (fictional Microsoft) database. Using a complete BI workflow, the project uncovers patterns that help improve operational and strategic business decisions.

The analysis includes:

End-to-end ETL pipeline using MySQL and Power BI

DAX-based data modelling, calculated columns & measures

Interactive dashboards for sales, profit, forecasting, customer analysis, and employee performance

Statistical hypothesis testing in Python (Two-sample T-test & One-way ANOVA)

Actionable insights to improve business profitability

# 🛠 Tools & Technologies

Power BI – Data modelling, DAX, visual analytics, forecasting

MySQL – Data extraction, table joins, SQL transformations

Python (Jupyter Notebook) – Exploratory data analysis & hypothesis testing

Pandas, SciPy, Matplotlib/Seaborn
